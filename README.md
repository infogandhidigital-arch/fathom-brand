## Quick Start

### Run the clock locally
1. Open `index.html` in a modern browser.
2. Use **Add time zone** to add clocks from the list.
3. Use each **Remove** button to remove a clock.
4. Toggle **Use 24-hour time** to switch between 12/24-hour display.

### Run tests
```bash
node --test tests/clock.test.mjs
```

### Brand Promise
**Fathom** = Deep understanding applied to AI, marketing, and business growth.

### Core Positioning
- **For:** Founders, marketers, and business leaders
- **Against:** Surface-level content, hype-driven advice, buzzword spam
- **Unique:** Research + insight + practical application

### Brand Personality
Intellectual • Curious • Confident • Direct • Practical

- **Color:** Deep Navy, Active Blue, Accent Teal
- **Typography:** Modern sans-serif (Inter/Relative)
- **Aesthetic:** Minimalist, data-driven, clean
